## Install
To install this app you go to the releases page and download the installer. Do __not__ download the release marked as Non-User as that is what the installer fetches. Then you run the app with arguments detailing.
Arguments:
Server:
```
./talos server
```
Client:
```
./talos client <Server IP Address>
```

E.g.
```
./talos client 192.168.68.123
```

The server prints out the url at which the server can be accessed.
